# buttter

`buttter` is intended to become a high-quality infinite-canvas diagramming application written in Rust using GPUI.

## Current Status

The repository is in pre-implementation setup. It contains no Rust product code, Cargo manifest, or runnable application.

Phase 0.5 permits only minimal repository documentation and configuration.

## Confirmed Intent

- macOS is the initial platform.
- Support for other platforms is a future goal, not a current claim.
