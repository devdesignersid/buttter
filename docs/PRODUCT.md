# Product Definition

## Confirmed Requirements

- Build an infinite-canvas diagramming application.
- Write the product in Rust using GPUI.
- Aim for high quality; measurable quality criteria have not yet been defined.

## Constraints

- macOS is the initial platform.
- Phase 0.5 repository setup is complete.
- No subsequent investigation phase is authorized until its scope and acceptance criteria are separately approved.
- The current repository guardrail work does not permit Rust or Cargo changes, dependency installation, GPUI work, CI implementation, or product code.

Repository workflow and review constraints are defined in [AGENTS.md](../AGENTS.md).

## Unknowns

- The first product behavior and its acceptance criteria.
- Measurable quality targets.
- The GPUI revision and integration approach.
- Product behavior beyond the confirmed infinite-canvas diagramming intent.
- The public product name.

## Explicitly Deferred Decisions

- Rust project initialization and dependency selection.
- GPUI proof-of-concept work.
- Support for platforms other than macOS.
- A feature roadmap.
- Repository licensing.
